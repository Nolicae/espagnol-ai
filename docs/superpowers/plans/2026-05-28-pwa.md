# PWA Espagnolai — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre Espagnolai installable sur iPhone et Android sans changer le comportement fonctionnel actuel.

**Architecture:** Approche minimaliste — un Service Worker qui met en cache les assets statiques (HTML, SVG, manifest) et laisse passer les appels API dynamiques (Groq, TTS) en network-first. Les meta tags Apple déjà présents dans l'HTML sont complétés par l'ajout de l'icône Apple touch.

**Tech Stack:** Vanilla Service Worker API (no libs), Vercel static hosting, iOS Safari Web App, Android Chrome PWA.

## Task 2: Créer le Service Worker

**Files:**
- Create: `service-worker.js` (à la racine du projet, côté `index.html`)

- [ ] **Step 1: Créer `service-worker.js`**

Créer le fichier `service-worker.js` à la racine avec ce contenu exact:

```javascript
const CACHE_NAME = 'espagnolai-v1';

// Assets statiques à mettre en cache
const STATIC_ASSETS = [
  '/',
  '/index.html',
  '/manifest.json',
  '/icons/icon.svg',
];

// Préfixes des URLs dynamiques → toujours network first
const NETWORK_FIRST_PATTERNS = [
  '/api/',
  'api.groq.com',
  'fonts.googleapis.com',
  'fonts.gstatic.com',
];

// Installation: mise en cache des assets statiques
self.addEventListener('install', event => {
  event.waitUntil(
    caches.open(CACHE_NAME).then(cache => cache.addAll(STATIC_ASSETS))
  );
  self.skipWaiting();
});

// Activation: suppression des anciens caches
self.addEventListener('activate', event => {
  event.waitUntil(
    caches.keys().then(keys =>
      Promise.all(
        keys.filter(k => k !== CACHE_NAME).map(k => caches.delete(k))
      )
    )
  );
  self.clients.claim();
});

// Fetch: cache-first pour assets statiques, network-first pour APIs
self.addEventListener('fetch', event => {
  const url = event.request.url;

  // Network-first pour les APIs et fonts
  const isNetworkFirst = NETWORK_FIRST_PATTERNS.some(p => url.includes(p));
  if (isNetworkFirst) {
    event.respondWith(
      fetch(event.request).catch(() => caches.match(event.request))
    );
    return;
  }

  // Cache-first pour les assets statiques
  event.respondWith(
    caches.match(event.request).then(cached => {
      if (cached) return cached;
      return fetch(event.request).then(response => {
        // Ne cache que les réponses valides
        if (!response || response.status !== 200 || response.type === 'opaque') {
          return response;
        }
        const toCache = response.clone();
        caches.open(CACHE_NAME).then(cache => cache.put(event.request, toCache));
        return response;
      });
    })
  );
});
```

- [ ] **Step 2: Vérifier la structure du fichier**

Confirmer que:
- `CACHE_NAME = 'espagnolai-v1'` est défini
- Les 3 event listeners (`install`, `activate`, `fetch`) sont présents
- `STATIC_ASSETS` contient bien `'/'`, `'/index.html'`, `'/manifest.json'`, `'/icons/icon.svg'`

- [ ] **Step 3: Commit**

```bash

git commit -m "feat(pwa): add service worker with cache-first strategy"
```

## Task 3: Enregistrer le Service Worker dans index.html

**Files:**
- Modify: `index.html` — ajouter avant `</body>` (après le `</script>` existant)

- [ ] **Step 1: Ajouter l'enregistrement du SW**

Dans `index.html`, **juste après `</script>` et avant `</body>`**, ajouter:

```html
<script>
  if ('serviceWorker' in navigator) {
    window.addEventListener('load', () => {
      navigator.serviceWorker.register('/service-worker.js')
        .then(reg => console.log('[SW] Registered:', reg.scope))
        .catch(err => console.warn('[SW] Registration failed:', err));
    });
  }
</script>
```
